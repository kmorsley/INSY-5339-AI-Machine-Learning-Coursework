# Homework 1 - Student Performance Analysis

This assignment analyzes the `student_performance.csv` dataset using Python.

## Objectives
- Load and inspect the student performance dataset
- Display the first five rows
- Calculate mean, median, minimum, maximum, and standard deviation for:
  - Study Hours
  - Attendance Percentage
  - Exam Score
- Count students by performance category
- Create a pie chart showing the distribution of performance categories
- Review and improve Copilot-generated code for clarity, readability, and reusability
- Export summary statistics and performance-category counts to CSV files
- Document code improvements and student contributions in a Markdown file

## Files
- Final Python analysis file
- `student_performance.csv`
- `summary_statistics.csv`
- `performance_category_counts.csv`
- Performance category pie chart
- Code changes documentation
